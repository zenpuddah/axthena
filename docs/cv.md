# Axthena — CV wording

## Recommended entry

**Axthena — Evidence-Backed Research Platform**

*C++20, Python, Neo4j, React, TypeScript, applied AI*

- Built a C++/Neo4j research platform that turns publisher articles into a queryable
  graph of organisations, activities, events and claims with exact source evidence.
- Implemented configurable Python ingestion with HTTP caching, bounded retries,
  scheduling and resumable jobs, plus validated AI extraction and domain matching.
- Delivered a conversational graph workspace and reproducible processing workflow;
  verified a 48-report corpus through 205 native checks, 17 Python tests, five
  frontend tests, retained-response replay and independent backup/restore.

## Short version

Built an evidence-backed research application using C++20, Neo4j, Python and React,
combining automated ingestion, validated AI queries and interactive graph exploration
with exact source traceability and reproducible published runs.

## Interview introduction

“Axthena helps investigate what selected sources report about companies. Python
collects articles, C++ validates and prepares structured records, Neo4j stores the
connected information, and a React workspace lets you ask questions and inspect
the passages behind each result. My focus was preserving evidence and separating
model suggestions from validated application behavior.”
